## v1.2 — 視覺修正輪（檢查點 `e297cd70`）

使用者實際遊玩後提出四項視覺問題，本輪逐一修正。

**小美（操場）頭髮透明**：早期去背使用大容差全域鍵值，把黑色頭髮誤刪成透明。改以保守的外部連通策略重新去背（`cutout_v4.py`），頭髮恢復實心。

**HOM-02 比例與朝向錯誤**：小美與媽媽分別生成後各自縮放，導致比例失真且兩人背對。改為單張雙人同框圖，從構圖階段鎖定比例與互動朝向。同時在 `Case` 型別新增 `focusName` / `focusGender` 覆寫欄位，讓代名詞邏輯在單筆 characters 的情況下仍能正確判斷。

**COM-01 缺少旁人與離開動作**：尷尬情緒的教學重點是「有人看到了」，原場景無旁觀者。重新生成背景，左後方加入兩位轉頭看過來的人；小豪的姿態改為低頭往旁邊走開。

**COM-02 比例落差如小人國**：阿嬤與小宇的縮放落差過大。同樣改為雙人同框圖，站著的小宇頭部略高於坐著的阿嬤，比例符合現實。案件敘述文字同步調整為與新畫面一致（原文說「沒有人停下來」但畫面已有小宇遞水）。

所有編號熱點座標依新背景重新校準。

## v1.1 — 回饋修正輪（檢查點 `a6bc28f0`）

使用者提出六項回饋，本輪全部處理。

**代名詞正確化**：原本全部使用「他」。新增 `Character.gender` 欄位與 `client/src/game/pronoun.ts` 模組，依焦點角色性別動態輸出「他／她」。小美、小琳、媽媽、阿嬤皆改為「她」。首頁副標亦改為性別中立寫法。

**ABC 改為橫式表格**：原為縱向清單。重寫 `AbcBoard.tsx` 為橫式佈局——上方例子卡片橫排、下方 A／B／C 三欄橫排，先點卡片再點欄位即歸位，可點欄位內卡片取回。橫向順序與「前因 → 行為 → 後果」的時間流一致。

**強化答對回饋**：使用者反映答對的強化效果不明顯。新增 `HitBanner.tsx`（蓋章節奏的階段肯定橫幅）與 `ScoreCard.tsx`（結案評分卡），並在 `ChoiceButton` 加上 `hit-glow` 柔和強調與印章式正解標記。新增 `scoring.ts` 模組，含分數計算、三級星等（首席／資深／見習偵探）與九句鼓勵語庫。分數下限固定 60 分。

**修正人物懸浮**：家庭場景角色未站在地面上。重寫 `CaseStage.tsx` 的地面基準線邏輯，角色定位改以底部為錨點。

**人物改為有動作的姿態**：原本所有角色都是證件照式站姿。重新生成全部角色圖，姿態直接對應案情（低頭壓考卷、蹲在積木旁、伸手要平板、捏著衣角、低頭走開等）。

**場景承載案情資訊**：原本只有地點背景，資訊全靠文字。為每件案子生成專屬背景圖，畫面中包含案情關鍵物件（考卷、足球、積木箱、平板、時鐘、籃球、長椅、水杯等），並新增 `StageProp` 編號熱點供點擊就近觀察，點過變綠色打勾。案件列表頁也加上各案縮圖。

## v1.0 — 首個可遊玩版本（檢查點 `738bce4b`）

依使用者選定的 B 方案（半擬真、低刺激）實作首個完整可遊玩版本。

建立六階段關卡引擎（`engine.ts`）：觀察線索 → 命名情緒 → 讀心推理 → 前因後果 → 想辦法 → 結案報告，其中前五階段計分。引擎完全不知道任何特定案件的存在，所有內容皆為純資料。

完成七件案子涵蓋三場景（學校、家庭、社區）與六種目標情緒（傷心、生氣、害怕、尷尬、孤單）。建立八種情緒的詞庫（含兒童語言定義與身體線索）與八條共用策略庫（分 regulate／reframe／act 三類）。

實作低刺激回饋機制：答錯不用紅色、不震動、不出聲，改以柔和退回動畫加「為什麼不是」的便條紙說明，並形成「已排除」視覺狀態。所有動畫在 `prefers-reduced-motion` 下全域關閉。按鈕採大命中區設計。

進度以 `localStorage` 記錄（鍵值 `emotion-detective-progress-v1`），首頁「偵探手冊」側欄顯示破案數與首次答對率。
