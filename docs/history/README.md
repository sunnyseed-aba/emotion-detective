# docs/history/ — 開發歷程原始工作筆記

> 這個目錄保存開發過程中產生的**原始工作筆記**，未經整理與潤飾。
>
> 正式交付文件在上一層 `docs/`。本目錄的價值在於：讓接手者理解專案是怎麼演進的、
> 每個決定當時面對什麼問題、哪些嘗試失敗過。若只讀最終程式碼，會看不到這些脈絡。

## 素材世代與 URL 對照

專案的圖片素材經歷四個世代。v1（紙劇場風格）作廢，v2 為首版半擬真，v3 為「有動作姿態＋案情物件」大改版，v4 為針對四個缺陷的重生。

| 檔案 | 內容 |
| --- | --- |
| `ASSET_MAP_V3.md` | v3 素材生成計畫與預定用途 |
| `ASSET_MAP_V3_FINAL.md` | v3 去背上傳後的最終 URL 對照 |
| `ASSET_MAP_V4.md` | v4 重生素材的計畫 |
| `ASSET_MAP_V4_FINAL.md` | v4 最終 URL 對照 |
| `ASSET_STATE_FINAL.md` | 修正後的 sprite URL 狀態總表 |

目前程式碼實際引用的素材，請以 `assets/ASSET_MANIFEST.md` 為準（那份是交付版對照表，含未採用素材與原因）。

## 視覺缺陷診斷與修正紀錄

這幾份是最有參考價值的部分。它們記錄了 AI 生成素材在實務上會遇到的具體失敗模式，以及對應的解法。若未來要新增案件並生成素材，**建議先讀這幾份再開始**，可避免重複踩同樣的坑。

| 檔案 | 記錄的問題 |
| --- | --- |
| `VISUAL_DIAGNOSIS.md` | 最早發現的角色懸浮、姿態過於靜態問題 |
| `V3_DIAGNOSIS.md` | v3 素材的透明背景失敗、定位偏移 |
| `V3_PLACEMENT_AUDIT.md` | 逐案檢視角色定位與比例的稽核紀錄 |
| `V3_HOTSPOT_RESULT.md` | 編號熱點座標校準的結果與殘留誤差 |
| `V3_FINAL_CHECK.md` | v3 輪次的收尾驗證與待修項 |
| `V4_DIAGNOSIS.md` | 頭髮被去背誤刪成透明、人物比例失真的成因分析 |
| `V4_GEN_REVIEW.md` | v4 重生素材的逐張評估 |
| `V4_EDIT_PLAN.md` | v4 素材整合前的精確程式碼修改計畫 |
| `V4_VERIFY.md` | v4 輪次的驗證結果 |
