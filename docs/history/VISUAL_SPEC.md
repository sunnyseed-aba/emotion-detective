# 情緒偵探社 — 視覺規範（已與使用者確認）

## 決議紀錄

使用者為督導身分，使用對象為 **6–12 歲 ASD 與發展遲緩兒童**。
經風格樣本比較後，確認採用 **樣本 B：半擬真 · 低刺激**。
紙劇場／紙偶風格（v1 素材）已作廢，不再使用。

擬真照片版本（樣本 C）**暫不製作**，但資料模型保留 `spriteReal` /
`backdropReal` 欄位，未來補圖即可切換，不需改動程式。

## 人物繪製規範

- 寫實人體比例、寫實臉部解剖結構
- 眼睛正常大小，正常頭身比
- 嚴禁：卡通、動漫、Q 版、大眼放大、誇張變形
- 表情依 **FACS 真實臉部肌肉動作** 繪製，不使用符號式表情
  （不畫淚滴符號、不畫爆青筋、不畫汗滴）
- 柔和繪畫質感（soft digital painting），避免恐怖谷與注視壓力
- 全身正面站姿、雙腳可見、雙手自然垂放
- 綠幕生成後以 `dechroma.py` 去背，輸出透明 PNG，高度統一 1400px

### FACS 表情對照

| 情緒 | 真實肌肉動作 |
|---|---|
| 傷心 | 內側眉毛上揚並靠近、上眼瞼下垂、嘴角下拉、下巴微低 |
| 生氣 | 眉毛下壓並靠近、眼瞼緊繃、上下唇緊壓成線、下巴前推 |
| 害怕 | 眉毛上揚並靠近、上眼瞼大幅上抬露出眼白、嘴角水平後拉 |
| 尷尬 | 視線迴避向側下、單邊嘴角內收、雙頰泛紅、肩膀內縮 |
| 開心 | 嘴角上揚並向外、眼輪匝肌收縮產生眼角細紋（真笑） |
| 驕傲 | 下巴微抬、輕微閉唇笑、胸口挺起、肩膀後展 |
| 驚訝 | 眉毛整體上揚、上眼瞼上抬、下顎放鬆成小圓口 |
| 孤單 | 視線下垂、表情低張力、身體朝內收、與他人有明顯距離 |

## 場景繪製規範

- 物件比例、透視、材質皆寫實，不用扁平剪影
- **刻意去雜訊**：僅保留敘事必要物件，無圖案、無裝飾、無雜物
- 背景低對比、柔和散射光、無強烈陰影、淺景深模糊
- **人物必須是畫面中對比最高的元素**，自然引導視覺注意臉部
- 中央下方保留空白區供角色定位，避免與家具重疊

## 低刺激互動規範

- 低飽和配色，無霓虹、無發光、無漸層轟炸
- 無閃爍動畫、無突發音效、無倒數計時壓力
- 大字級、大命中區（最小 44px）
- 答錯不使用紅色警示與震動，改為卡片輕輕退回原位
- 尊重 `prefers-reduced-motion`
