# 情緒偵探社 — 視覺設計腦力激盪

目標使用者：6–12 歲兒童（個案），由治療師／督導／家長／教師陪同操作。
核心體驗：觀察 → 推理他人心思（心智理論）→ 拆解前因後果 → 選擇因應策略。

---

## 三種風格方向

### 方向 A：紙劇場偵探社（Paper Theatre Detective）
**簡述**：以剪紙劇場、牛皮紙檔案夾與蠟筆質感構成的「偵探事務所」。溫暖、手作、低刺激，情緒像一張張可翻閱的線索卡，讓孩子在安全的紙上世界裡處理真實情緒。
**Probability**: 0.07

### 方向 B：情緒天氣站（Emotion Weather Station）
**簡述**：把情緒比喻為天氣系統，畫面以柔和水彩雲層、氣壓計與晴雨圖表構成。強調「情緒會流動、會轉變」的隱喻。
**Probability**: 0.04

### 方向 C：黏土小鎮（Claymation Town）
**簡述**：停格動畫黏土質感的立體小鎮，角色是可捏塑的黏土人偶，強調可塑性與「行為可以被改變」。
**Probability**: 0.03

---

## 選定方向：A — 紙劇場偵探社

選擇理由：手作紙感的低飽和材質對感官敏感的個案更友善（避免高對比霓虹刺激）；「檔案卡／線索卡」的隱喻天然對應 ABC 分析與心智理論推理的卡片式互動；紙劇場舞台的層次結構讓 3D 場景可用平面剪影堆疊實現，技術風險低且視覺一致。

### Design Movement
德式紙偶劇場（Papiertheater）× 中世紀手作繪本插畫 × Wes Anderson 式對稱舞台構圖，混入 1950 年代偵探檔案的排版語言（打字機標籤、印章、迴紋針）。

### Core Principles
1. **一切都是紙**：每個物件都有紙的厚度、裁切邊緣與微微投影，沒有玻璃或霓虹。
2. **舞台縱深**：畫面由前景／中景／背景三層剪紙構成，鏡頭橫移時產生視差，暗示「觀察需要層次」。
3. **線索可觸**：情緒與想法一律以實體卡片呈現，可拾起、翻面、歸檔，抽象心理狀態被物質化。
4. **低刺激高清晰**：飽和度受控、字級大、命中區大，適合注意力與感官調節需求。

### Color Philosophy
基底是牛皮紙與亞麻布的暖中性色（`oklch(0.93 0.03 85)` 紙白、`oklch(0.82 0.05 80)` 卡紙、`oklch(0.28 0.03 60)` 墨褐），情緒不用刺眼原色，而用「染料色」：喜悅芥黃、傷心靛藍、生氣磚紅、害怕鼠尾草綠、尷尬乾燥玫瑰、驕傲赭橙。情緒色只出現在情緒相關元件上，因此孩子看到某個顏色就能建立語意連結。

### Layout Paradigm
非居中、非網格。採「檔案桌面」佈局：左側是垂直的偵探卷宗側欄（場景、任務、徽章），右側是佔據大部分視野的紙劇場舞台，下緣是可橫向滑動的線索卡托盤。對話與推理選項以貼在舞台右側的便條紙形式出現，略帶旋轉角度（-2°～3°），刻意避免規整對齊。

### Signature Elements
1. **裁切紙緣 + 雙層投影**：所有卡片有不規則手撕邊與極輕的紙張投影。
2. **打字機標籤與橡皮章**：任務標題用打字機字樣的標籤紙，正確答案落章「已破案」。
3. **迴紋針與縫線**：卡片群組以迴紋針或虛線縫線視覺化連結，ABC 因果鏈就是三張卡被縫在一起。

### Interaction Philosophy
互動要像在桌上翻動實體物件：卡片被「拿起」（輕微上浮＋投影變深），被「放下」（下沉＋投影收斂）。錯誤答案不做紅色警示閃爍，而是卡片被輕輕推回原位，保留嘗試的尊嚴。

### Animation
- 卡片拾起：140ms `cubic-bezier(0.23,1,0.32,1)`，translateY(-6px) + shadow 加深。
- 卡片翻面：220ms 3D rotateY，背面顯示情緒說明。
- 舞台換景：紙幕由上而下滑落 320ms，換好後上升，模擬劇場換幕。
- 線索卡入場：stagger 60ms 逐張落下並帶 -3°～3° 隨機旋轉。
- 落章效果：橡皮章由上壓下 180ms scale(1.15 → 1) + 墨跡透明度漸入。
- 全部非必要動態包在 `prefers-reduced-motion: no-preference`。

### Typography System
標題用 `Zen Maru Gothic`（圓潤、親和、支援繁中）作為顯示字；正文與 UI 用 `Noto Sans TC`；標籤與檔案編號用等寬 `Courier Prime` 製造打字機檔案感。標題 clamp 到 32–48px，正文不小於 17px，行高 1.7，兒童可讀性優先。

### Brand Essence
「情緒偵探社」是一間讓 6–12 歲孩子練習讀懂他人心思的紙上事務所；給需要社交情緒訓練的個案與陪伴他們的專業人員；不同之處在於它不只問「他什麼感覺」，而是追問「他為什麼這樣想」。
個性形容詞：好奇的、溫厚的、有條理的。

### Brand Voice
像一位語氣平穩的資深偵探對小助手說話：邀請觀察，不下評斷；用「我們」而不是「你應該」。
範例句一：「先別急著結案。他的臉在說一件事，他的心可能在說另一件。」
範例句二：「收集三張線索卡，我們就能拼出這件事的來龍去脈。」

### Wordmark & Logo
標誌為一枚「放大鏡框住一顆心」的線稿印章：放大鏡的圓框以手繪不完美的圓構成，鏡內是簡化的心形，鏡柄斜向右下 45°，整體像蓋在卷宗上的墨褐色橡皮章，邊緣帶輕微墨暈。文字標則用打字機字樣加底線，如檔案封面的手打標題。

### Signature Brand Color
**檔案墨褐 `oklch(0.32 0.045 62)`** — 用於標誌、印章、標題與所有線稿描邊，是整個品牌的骨架色；搭配牛皮紙底色，形成不可誤認的「舊卷宗」識別。

## Style Decisions（已與使用者確認，覆寫上方部分內容）

使用者為督導身分，使用對象為 6–12 歲 ASD 與發展遲緩兒童。經風格樣本
比較後，**人物與場景改採「半擬真 · 低刺激」（樣本 B）**，紙劇場／紙偶
風格的角色與場景素材已作廢。完整規範見 `VISUAL_SPEC.md`。

仍然保留的（介面層）：

- 卷宗／檔案的資訊架構隱喻：案件編號、線索卡、ABC 因果鏈縫在一起
- 檔案墨褐主色與牛皮紙底色、打字機字樣的檔案編號
- 字體系統（Zen Maru Gothic / Noto Sans TC / Courier Prime）
- 互動哲學：答錯不用紅色警示，卡片輕輣退回原位
- 動畫時長與 easing、`prefers-reduced-motion` 全面尊重

被覆寫的（舞台層）：

- 角色不再是剪紙紙偶，改為寫實比例、FACS 真實肌肉表情的柔和繪畫人物
- 場景不再是三層剪紙剪影，改為寫實透視、低對比、刻意去雜訊的背景圖
- 舞台不做視差橫移與紙幕換景；改為極輕的淡入，避免動態刺激
- 情緒染料色維持語意化用途，但飽和度再降一階（見 `emotions.ts`）

舞台層與介面層的分工原則：**畫面中對比最高的元素必須是人物的臉**，
因此介面色階一律壓低，不與人物競爭注意力。
