| `v3-char-mei-hom02_fix.png`（home-02 使用中） | 頭髮頂部有大片透明破洞，腿部與衣服有破洞；且此圖是「站姿伸手大喊」，與 home-02 的「伸手要平板」情境不合 |

## 比例問題根因
目前每個 sprite 的圖檔內身高佔比不同（有人滿版、有人留白），
而 `CaseStage` 用 `height: 64 * scale (%)` 直接套用圖檔高度，
導致實際人物身高不成比例（community-02 阿嬤看起來過大、小宇過小）。

## 修正策略
1. **重新生成** 四張人物圖：mei-sch02、mei-hom02＋mom-hom02（同一構圖含兩人以確保比例）、hao-com01（低頭走開）、community-01 需含旁觀者。
2. **community-02** 改用「阿嬤＋小宇同一張構圖」以徹底解決比例落差。
3. 生成時要求純白背景、人物不接觸畫框邊緣，方便乾淨去背。
4. 去背改為保守策略：只移除外部連通的白色區域，不使用容差過大的全域鍵值，避免刪到頭髮與淺色衣服。
