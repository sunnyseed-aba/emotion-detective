# 視覺問題診斷（依使用者回饋 + 截圖實查）

## 已確認的問題

| 問題 | 實際觀察 | 根因 | 對策 |
| --- | --- | --- | --- |
| 角色浮空 | HOM-01 小宇腳底落在茶几上；HOM-02 小美同樣站在茶几上，媽媽腳底落在地毯後緣但比例偏大 | `placement.y` 是人工估的百分比，與背景圖實際地面線不吻合。家庭背景圖的地板透視線約在畫面 78–86%，茶几在 y≈72% 位置 | 逐案重新標定地面線；並在背景圖生成時「保留空曠地面區」，讓人物有地方站 |

| 場景缺乏畫面資訊 | 教室只有桌椅、客廳只有沙發茶几、公園只有鞦韆長椅；案件的關鍵物件（考卷、積木塔、平板、便當）完全沒出現 | 背景圖是「通用場景」而非「案件場景」 | 改為每案一張場景圖，把關鍵物件畫進畫面；並在舞台加可點的物件熱點 |
| 阿嬤該是坐姿 | COM-02 阿嬤站著，但案件敘述是「坐在長椅上」 | 人物圖只有站姿一種 | 生成坐姿版本 |
