## 去背作法（沙盒端）
來源檔在 `/home/ubuntu/webdev-static-assets/v3-char-*.png`，
用 Pillow 讀取，取四角像素的主色作為 key colour，
以 RGB 距離閾值（約 60–80）建立 alpha mask，再對邊緣做 1px 羽化，
最後 `manus-upload-file --webdev` 重新上傳取得新 URL。
