# ABA Motivation Layer

## 本階段範圍

本層在不更動案件內容、五階段引擎、評分與圖片的前提下，加入第一版兒童學習支持。它不是治療方案，也不取代專業人員依個別孩子進行的功能性評估與教學調整。

## 已加入的互動

- **孩子主動求助的小專家**：提示不會自動彈出，避免打斷觀察與形成提示依賴。
- **最少到最多提示**：每階段有三層提示，依序為注意方向、具體線索、示範答案。
- **具體行為回饋**：答對後說明孩子剛才用了哪一種有效策略，而非只顯示「答對」。
- **線索種子**：用五顆成長種子呈現階段進度，不加入倒數、排名或失敗懲罰。
- **偵探筆記**：結案後收藏本案的心智理論概念，連結客觀事實與角色信念。

## Sunny Seeds 識別

Sunny Seeds 識別使用正式教學產品 Logo，並以其中的深藍、種子綠與暖橘建立 `client/src/brand/theme.ts` 的品牌 token。頁面只加入低彩度的陽光、種子與成長符號，沒有重繪或重新著色案件圖片。

正式 Logo、品牌色與字體提供後，應從 Brand Layer 統一替換；不應在個別元件寫死品牌值。

小專家角色使用 `client/public/brand/detective-advisor.png`。角色固定在右側提示卡的正常版面流內，不使用浮動覆蓋，因此不會遮住案件照片、人物或熱點。

## 後續產品決策

- 提示使用是否需要寫入進度資料，供教師或治療師查看。
- 強化物偏好是否讓孩子自行選擇，以及是否需要個別化。
- 小專家的正式角色、名字、語氣與插圖。
- 是否加入提示淡出（prompt fading）規則，以及由誰設定淡出條件。
