# SEL Content Roadmap

## 原則

目前三個場景（學校、家庭、社區）可作為第一輪兒童試玩的範圍。新增內容前，先觀察孩子是否能理解圖片、找到線索、完成選擇，以及提示需要到哪一層。案件畫面繼續採用較貼近生活的自然情境，不改成直接揭露答案的誇張卡通表情。

## 建議擴充面向

### 1. 自我覺察

- 察覺身體訊號與情緒強度
- 同一件事可能同時帶來兩種感受
- 分辨「我感覺」與「事情的事實」

### 2. 自我管理

- 等待、被拒絕與計畫改變
- 感官負荷升高時主動休息或求助
- 從衝動行為轉為可練習的替代行為

### 3. 社會覺察

- 別人知道的資訊可能和自己不同
- 理解無意、意外與故意的差別
- 辨識較細微或混合的表情與語氣

### 4. 人際技巧

- 加入遊戲、輪流與協商規則
- 被忽略、被打斷或意見不同時如何表達
- 衝突後道歉、修復與重新加入

### 5. 負責任的決定

- 比較不同策略的短期與長期結果
- 安全、尊重界線與尋求可信任成人
- 線上互動、群組訊息與數位公民情境

## 第一輪試玩後的優先順序

1. 記錄孩子最常卡住的階段與提示層級。
2. 訪談家長、教師或治療師最常遇到的三種生活情境。
3. 優先新增一個高頻情境，完成圖片與文字一致性檢查。
4. 用同一技能建立不同人物、地點與線索的泛化案件。
5. 確認孩子能在沒有答案型提示的情況下辨識，再擴大案件數量。

## 不建議現在加入

- 大量只更換人物名稱、但技能完全相同的案件。
- 用誇張情緒臉直接提示正確答案的圖片。
- 將眼神接觸或壓抑自我刺激行為當成所有孩子都必須達成的目標。
- 未經個別評估就把單一策略描述成唯一正確做法。
